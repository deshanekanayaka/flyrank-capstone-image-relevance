# Triage labels

The skills name five canonical triage roles. This file maps each role to the label string
that the issue tracker of this repository uses.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer must evaluate this issue    |
| `needs-info`               | `needs-info`         | Waiting for more information from the reporter |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Needs implementation by a person         |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

If a skill names a role, for example "apply the AFK-ready triage label", use the matching
label string from this table.

Edit the right-hand column to match the vocabulary that you use.
